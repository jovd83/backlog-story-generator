# Security Policy

## Reporting a Vulnerability

Please do not open public GitHub issues for suspected security vulnerabilities.

Report security concerns privately to the maintainer through the contact path documented in [SUPPORT.md](./SUPPORT.md). Include:

- a clear description of the issue
- affected files, commands, or workflows
- reproduction steps when available
- impact assessment if known

## Response Expectations

The maintainer will review the report, confirm whether it is in scope, and coordinate remediation guidance as appropriate.

## Scope Notes

This repository primarily contains skill instructions, reference material, scripts, and GitHub workflow automation. Security reports should focus on issues that could affect users, contributors, or downstream automation consumers.
