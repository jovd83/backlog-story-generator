# Example Packs

These examples demonstrate the canonical story contract across multiple domains.

Included source inputs:
- `input-checkout-requirements.md`: commerce checkout workflow
- `input-analytics-dashboard-widget.md`: admin reporting with performance expectations
- `input-warehouse-operations.md`: fulfillment workflow with operational and audit concerns
- `input-role-access-management.md`: admin permissions and access-control workflows
- `input-healthcare-appointment-scheduling.md`: clinic appointment search, booking, and cancellation behavior
- `input-field-service-dispatch.md`: dispatcher assignment and technician status workflows

Generated examples live under `examples/generated/` and intentionally:
- use globally unique story IDs
- follow the epic-folder and story-file naming rules
- include both required sections and selective optional sections
- remain valid under the parser, schema, validator, and exporter

Use these examples when changing the story template, schema, validation rules, or export logic.
