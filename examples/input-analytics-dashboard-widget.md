# Analytics Dashboard Widget Requirements

Build an admin dashboard widget that shows sales trends.

Users must be able to:
- switch between 7, 30, and 90 day date ranges
- filter the chart by region
- see refreshed chart data and summary totals after changing filters

Additional constraints:
- the widget should load in under 1 second for supported ranges
- failed data loads should show a clear retry path
- the widget should be usable on laptop screens without horizontal scrolling
