# Field Service Dispatch Sample

Create backlog stories for a field service dispatch workflow used by dispatch coordinators and mobile technicians.

Users must be able to:
- view newly created service jobs
- assign a technician to a job based on territory and skill match
- update a job status when the technician is en route, on site, or completed
- capture customer-visible arrival windows

Additional constraints:
- dispatchers must not assign technicians outside their supported territories unless an override is allowed
- status updates should stay visible to customer support
- mobile technicians may work with intermittent connectivity
