# Healthcare Appointment Scheduling Sample

Create backlog stories for a patient appointment scheduling flow used by clinic staff and patients.

Users must be able to:
- search for available appointment slots by specialty and location
- book an appointment using an available slot
- reschedule an upcoming appointment
- cancel an appointment with a visible cancellation policy

Additional constraints:
- appointment availability must prevent double-booking
- cancellation policy messaging must be shown before the cancellation is confirmed
- reminder preferences should support SMS or email if the clinic enables them
