# Project-Local Memory

Use this directory only for deliberate, repository-scoped persistent memory.

Good candidates:
- stable local naming conventions
- approved export defaults
- a vetted assumptions ledger for repeated backlog work in this repository

Do not store:
- transient scratch notes
- secrets
- cross-agent shared-memory data
- auto-promoted conversation summaries
