# Support

## What This Repository Supports

This repository supports:

- the `backlog-story-generator` skill contract
- bundled references and templates
- validation, quality, export, packaging, and repo-health scripts
- example packs, eval artifacts, and GitHub maintenance workflow

## Best Way To Get Help

- Open a GitHub issue for bugs, contract problems, documentation gaps, or tooling regressions.
- Use the issue templates when they fit.
- For security-sensitive concerns, follow [SECURITY.md](./SECURITY.md) instead of filing a public issue.

## What To Include

Include enough context to reproduce the problem:

- repository version or commit
- command run
- input story pack or source artifact
- observed output or error
- expected behavior

## Support Boundaries

This repository does not provide:

- custom backlog consulting for private product requirements
- support for downstream backlog tools beyond the documented CSV exports
- guarantees for forks that diverge materially from the published contract
