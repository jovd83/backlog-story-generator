# Support

If you encounter issues or have questions about using the Backlog Story Generator, please use the following paths:

## Community Support

- **GitHub Issues**: Use [GitHub Issues](https://github.com/jovd83/backlog-story-generator/issues) for bug reports, feature requests, and general questions.

## Security Reporting

As noted in [SECURITY.md](./SECURITY.md), please report security vulnerabilities privately. You can contact the maintainer (@jovd83) via their GitHub profile or by opening a draft PR with "SECURITY" in the title if private vulnerability reporting is not yet enabled on the repository.

## Commercial Support

This is an open-source project. For organizational onboarding, custom adaptations, or dedicated support, please contact the maintainer directly.
