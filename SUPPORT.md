# Support

## Getting Help

Use GitHub issues for bug reports, documentation gaps, and enhancement requests when the topic is safe to discuss publicly.

- Bug reports: use the templates under `.github/ISSUE_TEMPLATE/`
- Contract or repository changes: use the matching issue template when available

## Maintainer Contact

For repository maintenance questions, review ownership information in [.github/CODEOWNERS](./.github/CODEOWNERS).

## Security

For suspected vulnerabilities, follow the private reporting guidance in [SECURITY.md](./SECURITY.md) instead of filing a public issue.
